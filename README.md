# made.expert

Static site for MADE, the practice of Katerina Braga. Plain HTML with inline styles, no build step. Hosted on GitHub Pages.

## Structure

```
index.html                 homepage
about.html                 About page
insights/                  Insights listing and articles
legal/                     Impressum, Datenschutzerklärung, AGB (noindex)
assets/images/             photos, logo, favicons, OG image
assets/fonts/              self-hosted Inter and Poppins (no Google Fonts requests)
sitemap.xml, robots.txt, llms.txt, CNAME, site.webmanifest
```

## Design rules

- Three type sizes only: headings (--fs-l), accent lines and card titles (--fs-m), all other text (--fs-s).
- One text colour per background: cream-white on dark navy, dark navy on light cards.
